# Story 2.4: Histórico de aprovação visível ao funcionário

## Status: Approved

## Description

Como **funcionário**, quero ver quem aprovou ou rejeitou meu relatório e o comentário, **para** entender a decisão e ajustar caso necessário.

> **Contexto:** as tabelas `report_approvals` (aprovações de relatório inteiro) e `expense_reviews` (revisões item-a-item) acumulam histórico desde 2026-02. Mas a UI atual em `ReportDetail.tsx` não mostra esse histórico de forma consolidada. Funcionário hoje só vê o status atual.

## Acceptance Criteria

- [ ] **Given** sou owner de um relatório que já foi decidido, **when** acesso `/app/reports/:id`, **then** vejo uma seção "Histórico" com:
  - Cada entrada de `report_approvals` ordenada por `created_at` desc, mostrando: nome do aprovador, decisão (aprovada/rejeitada), comentário (se houver), timestamp relativo (ex.: "há 2 dias")
  - Cada entrada de `expense_reviews` agrupada por despesa (ex.: "Despesa X reprovada por Y — comentário Z")
- [ ] **Given** o relatório nunca foi submetido (status=draft), **when** acesso o detalhe, **then** a seção "Histórico" **NÃO aparece** (evita ruído).
- [ ] **Given** estou em mobile (390x844), **when** vejo a seção "Histórico", **then** ela é **colapsada por padrão** (Accordion ou similar) com contador "5 entradas" — clicar expande.
- [ ] **Given** sou um manager visualizando relatório de outro usuário, **when** acesso o detalhe, **then** também vejo o histórico (read-only) — útil para contexto.
- [ ] **Given** o histórico está aberto, **when** olho cada entrada, **then** o avatar/inicial do aprovador é visível, e o tempo relativo está em pt-BR (`date-fns/locale/ptBR` formatDistanceToNow).
- [ ] **Given** uma entrada tem comentário muito longo (>200 chars), **when** ela renderiza, **then** mostra preview com "ler mais" (truncate + click expand).

## Technical Notes

### Hook novo `useReportHistory`
- **Arquivo:** `src/hooks/useReportHistory.ts` (novo)
- **Tipo unificado:**
  ```ts
  type HistoryEntry =
    | { kind: 'report_approval'; id: string; approver_id: string; approver_name: string | null;
        decision: 'approved' | 'rejected'; comment: string | null; created_at: string }
    | { kind: 'expense_review'; id: string; reviewer_id: string; reviewer_name: string | null;
        expense_id: string; expense_description: string | null; decision: 'approved' | 'rejected';
        comment: string | null; created_at: string };
  ```
- **Query:** dois selects paralelos via `Promise.all`:
  ```ts
  // 1) report_approvals com profile do approver
  supabase.from('report_approvals')
    .select('*, profiles:approver_id(full_name)')
    .eq('report_id', reportId)
    .order('created_at', { ascending: false });

  // 2) expense_reviews + expense.description com profile do reviewer
  supabase.from('expense_reviews')
    .select('*, profiles:reviewer_id(full_name), expenses:expense_id(description)')
    .eq('report_id', reportId)
    .order('created_at', { ascending: false });
  ```
- Mapear para `HistoryEntry[]` e fazer merge sort por `created_at` desc.
- `enabled: !!reportId` no useQuery.

### UI no `ReportDetail.tsx`
- **Arquivo:** `src/pages/app/ReportDetail.tsx`
- Adicionar nova seção (após o bloco de status/actions, antes da tabela de despesas):
  ```tsx
  {report?.status !== 'draft' && (
    <ReportHistory reportId={id!} />
  )}
  ```
- **Componente novo:** `src/components/reports/ReportHistory.tsx`
  - Recebe `reportId`. Internamente usa `useReportHistory(reportId)`.
  - Renderiza `<Accordion type="single" collapsible defaultValue={isMobile ? undefined : "history"}>` (colapsado em mobile, aberto em desktop). Header mostra contagem.
  - Cada entrada renderiza com `<Avatar>` (inicial do nome), nome do aprovador, badge da decisão (verde/vermelho), comentário com truncate >200 chars, timestamp relativo.
  - Empty state se array vazio: "Nenhuma decisão registrada ainda."
  - Loading skeleton: 3 linhas placeholder.
  - Error state: toast "Não foi possível carregar histórico" + retry.

### Tempo relativo em pt-BR
- Usar `formatDistanceToNow` do `date-fns` com locale `ptBR`:
  ```ts
  import { formatDistanceToNow } from 'date-fns';
  import { ptBR } from 'date-fns/locale';
  formatDistanceToNow(parseISO(entry.created_at), { addSuffix: true, locale: ptBR });
  // → "há 2 dias", "há 3 horas", etc.
  ```

### Truncate de comentário longo
- Componente local `<ExpandableText text={entry.comment} maxChars={200} />` (criar inline em `ReportHistory.tsx`):
  - Estado `expanded` boolean
  - Se `text.length > maxChars && !expanded`: mostra `text.slice(0, maxChars) + '…'` + botão "ler mais"
  - Se `expanded`: mostra texto completo + botão "ver menos"
